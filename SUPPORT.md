# Support

Forma is maintained by one person. This page says what to expect.

## Questions and bugs

Open a [GitHub issue](https://github.com/zachshallbetter/forma/issues). Use the issue templates;
a minimal reproduction is the fastest path to a fix.

Responses are best-effort with no SLA. There is no guaranteed response or fix time.

## Versioning

Releases are marked with git tags (currently `v0.1.0`).

## Security reports

Do not open a public issue for a vulnerability. Follow [SECURITY.md](SECURITY.md), which
uses GitHub private vulnerability reporting.
